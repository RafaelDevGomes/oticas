Sistema de Gerenciamento de Ótica
Sobre o projeto

Uma ótica identificou a necessidade de modernizar e organizar seus processos internos por meio de um sistema informatizado que facilite o gerenciamento de suas atividades diárias. Com o objetivo de atender a essa necessidade, a empresa contratou os alunos Gabriel Henrique e Rafael Gomes, responsáveis pelo desenvolvimento de um sistema personalizado de acordo com suas demandas.

O projeto tem como finalidade desenvolver uma solução prática, organizada e de fácil utilização, capaz de auxiliar a ótica no controle de suas operações, reduzindo a dependência de processos manuais e contribuindo para uma gestão mais eficiente.
Objetivo

Desenvolver um sistema que atenda às necessidades da empresa, oferecendo recursos que facilitem a organização das informações, o gerenciamento das atividades e a consulta aos dados necessários para o funcionamento do estabelecimento.
